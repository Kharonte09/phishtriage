¿Y cómo consigo el fichero .eml de un correo?
Gmail (web)Abre el correo → menú ⋮ arriba a la derecha del mensaje → Descargar mensaje. Te baja un .eml.
Outlook (escritorio)Arrastra el correo desde la lista hasta el escritorio, o Archivo → Guardar como y elige formato .eml.
Outlook (web)Abre el correo en ventana nueva → ⋮ → Guardar como.
Apple MailArrastra el correo a una carpeta del Finder.
ThunderbirdClic derecho en el correo → Guardar como → Archivo.
Sin descargar nadaAbre el mensaje original / ver código fuente, selecciona todo el texto, cópialo y pégalo aquí con Ctrl+V.

Importante: el fichero se analiza dentro de tu navegador. No se sube a ningún servidor, ni al mío ni a otro.

Ajustes de enriquecimiento

Las claves que escribas aqui se guardan solo en el localStorage de este navegador y viajan en las peticiones a VirusTotal / AbuseIPDB. En una pagina publica cualquiera con acceso al equipo puede leerlas: usa claves personales de solo lectura, nunca corporativas.

Recomendado: levanta cli/proxy.py en http://127.0.0.1:8787 y pon esa URL en "Proxy". Asi las claves viven en variables de entorno del proxy y no tocan el navegador.

La API publica de VirusTotal permite 4 peticiones/minuto: con 15000 ms vas sobrado.
