¿Cómo descargo el correo?

Necesitas el fichero del correo, no una captura de pantalla. Seguún lo que uses:

GmailAbre el correo → menú ⋮ → Descargar mensaje.
Outlook (programa)Arrastra el correo desde la lista hasta el escritorio.
Outlook (web)Abre el correo en otra ventana → ⋮ → Guardar como.
Apple MailArrastra el correo a una carpeta.
ThunderbirdClic derecho → Guardar como → Archivo.

Si no lo encuentras, hay un atajo que funciona en todos: busca la opción mensaje original o ver código fuente, selecciona todo el texto que salga, cópialo y pégalo aquí con Ctrl+V.
